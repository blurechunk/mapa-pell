# Mapa de la pell

Guia d'estudi de dermatologia en català. Pàgina publicada: https://blurechunk.github.io/mapa-pell/

- `index.html`: la guia sencera (dades, estils i codi en un sol fitxer).
- `img/`: fotografies clíniques de Wikimedia Commons amb llicència lliure; l'autor, la llicència i la font de cada imatge són a la mateixa guia.
- Les propostes del grup es desen en un full de Google a través d'un script d'Apps Script; la guia no conté cap dada personal.
